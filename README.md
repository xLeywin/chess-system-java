# Chess System Java
[![NPM](https://img.shields.io/npm/l/react)](https://github.com/xLeywin/chess-system-java/blob/main/LICENSE) 

# Sobre o projeto
O projeto consiste no desenvolvimento de um sistema de jogo de xadrez em modo console, aplicando os principais conceitos de Programação Orientada a Objetos com Java. O sistema implementa todas as regras do xadrez, incluindo movimentação das peças, captura, verificação de xeque e xeque-mate, além de movimentos especiais como roque, en passant e promoção de peão.
O objetivo principal é consolidar conceitos como encapsulamento, herança, polimorfismo, exceções e organização em camadas, seguindo uma estrutura limpa e bem definida.

# Como executar
1. Faça o download do arquivo chess-system.jar e salve o arquivo em uma pasta de sua preferência no computador.
2. Acesse a pasta onde o arquivo chess-system.jar foi baixado. Abra o terminal nessa pasta.
    - Windows: segure Shift, clique com o botão direito e escolha “Abrir janela do terminal aqui” ou "Abrir no terminal".
    - Linux/Mac: clique com o botão direito na pasta e selecione “Abrir no terminal”.
3. No terminal, digite o comando abaixo e pressione Enter:
    - java -jar chess-system.jar
  
![Imagem](https://github.com/xLeywin/Assets/blob/main/chess-system-java/image.png)

Peças:
- R (Rook) -> Torre
- N (Knight) -> Cavalo 
- B (Bishop) -> Bispo
- Q (Queen) -> Rainha
- K (King) -> Rei
- P (Pawn) -> Peão

Como jogar:
- Utilize cordenadas (Ex: a5, b6, h8) para selecionar uma peça e depois movê-la.
